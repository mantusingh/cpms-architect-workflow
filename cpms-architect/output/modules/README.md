# Module Deep-Dive Designs

This folder contains on-demand deep-dive documents for specific OCPP/OCPI modules
or profiles, generated by the `/design-module` skill.

## Usage

```
/design-module <module-name>
```

Each module gets its own subfolder: `output/modules/<module-slug>/`

## Module Document Contents

Each `<module-slug>-design.md` contains:
- Specification summary with section citations
- Service responsibilities and components
- Mermaid sequence diagrams for critical flows
- Data model (PostgreSQL DDL + Kafka + Redis)
- API surface (gRPC proto + GraphQL if external)
- Go interface/struct sketches
- ADR(s) for key design decisions
- Cross-references to C4 phase documents (if phases are complete)
