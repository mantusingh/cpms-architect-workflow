# CPMS Design Patterns

This folder contains reusable design patterns discovered during CPMS architecture
sessions. Each pattern is a standalone Markdown file.

## Pattern File Format

Each pattern file (`<pattern-name>.md`) follows this structure:

```markdown
# Pattern: [Name]

## Problem
[The problem this pattern solves]

## Solution
[The pattern itself — how it works]

## Context
[When to use this pattern — constraints and applicability]

## Trade-offs
[What you gain and what you give up]

## OCPP/OCPI Applicability
[Which spec sections or message types this pattern applies to]

## Example
[Concrete CPMS example showing the pattern in action]
```
