# CPMS Architectural Patterns & Learnings

This file is maintained by the CPMS Architect agent. It accumulates insights,
design patterns, and OCPP/OCPI edge cases discovered across sessions.

The agent reads this file at the start of every skill and surfaces relevant
learnings before beginning design work.

---

## How This File Works

At the end of each session where a new insight is discovered, the agent appends
an entry under a dated heading:

```
## YYYY-MM-DD

### [Short title]
**Context**: [What was being designed]
**Insight**: [The pattern or edge case]
**Applicability**: [When to apply this in future CPMS designs]
```
